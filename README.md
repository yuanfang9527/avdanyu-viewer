# 🎞 avdanyu-viewer · avdanyuwiki 本地作品查看器

基于 [avdanyuwiki](https://avdanyuwiki.com) 导出数据构建的**本地离线作品资料库与检索整理工具**：作品列表、多维搜索、实体画像、收藏整理全部在本机完成，不依赖任何在线服务；仅封面加载、标题翻译、外站链接等增强功能需要联网。

> ⚠️ **内容提示**：本项目管理的内容涉及成人媒体资料，仅适合年满 18 周岁、且所在地区法律允许的用户出于个人资料整理目的使用。

## ✨ 核心特性

- **全局搜索 + 9 大字段组合筛选** —— 一个搜索框同时检索标题、译名、番号、演员、导演、片商、标签、系列、类型；多词空格分隔为 AND 匹配，字段框可任意组合层层收窄
- **跨月份集中浏览** —— 全库一个列表，表格流 / 海报瀑布流双视图，年份速切、正倒序、随机漫游
- **实体详情画像抽屉** —— 点击任何演员 / 片商 / 系列 / 标签 / 类型 / 导演弹出全景统计；每个分组带独立筛选框与分页展开；跨字段一键联合检索，多层钻取可回溯
- **多元化个人整理** —— 影片⭐收藏、人物收藏（女优/男优/导演三组主题化管理）、实体收藏（片商/系列/标签/类型）、✓已看标记、🗑可还原回收站、🕒浏览历史（最近 100 部）、🔖关键词收藏、🛡️屏蔽词过滤
- **标题自动翻译（日→中）** —— 智谱 GLM 大模型（主引擎，需自备 API Key）→ 谷歌免费引擎（收底）→ MyMemory（单条兜底）三级自动降级；支持详情内原地手动精修译名
- **磁力链接实时检索** —— 打开详情时按番号抓取 JavBus / sukebei / btdig 并缓存 30 分钟，中字条目优先，BTIH 哈希校验
- **JavDB 評論區阅读** —— 详情抽屉内懒加载抓取 JavDB 观众评论（作者/评分/日期/正文），未收录与地区封锁均有明确提示
- **预告片本地播放 / 在线播放内嵌** —— 本地服务解析 FANZA 试看多画质直链；123av 纯播放器页内嵌观看，无站点杂质元素；在线正片可一键搜索迅雷字幕库挂载字幕（按时长吻合度排序、±0.5s 时间轴微调、可下载 srt）
- **深色 / 浅色主题**、搜索状态跨会话自动恢复、译文与封面本地持久化

## 🚀 快速开始

**环境要求**：Python 3.8+（仅标准库即可运行）+ 现代浏览器（Chrome / Edge）

1. **准备数据**：用油猴脚本 [`scripts/avdanyu-exporter.user.js`](scripts/avdanyu-exporter.user.js) 在 avdanyuwiki 导出月度数据（`2024-05.txt` 之类），放入 `avdanyu-data/months/`
2. **整合数据库**：在项目根目录运行
   ```bash
   python scripts/avdanyu-merge.py
   ```
3. **启动查看器**：双击 `start-viewer.bat`（首次会自动检测环境并打开浏览器），访问 `http://127.0.0.1:8971/avdanyu-viewer.html`
4. **退出**：关闭浏览器即可；需彻底关闭后台服务时双击 `stop-viewer.bat`

不配置任何 API Key 也能完整使用——翻译自动走免费谷歌引擎。

## 📁 项目结构

```
├── avdanyu-viewer.html      # 查看器主页面（纯前端，离线可用）
├── start-viewer.bat/.py     # 启动器（环境检测 + 拉起后台服务 + 打开浏览器）
├── stop-viewer.bat/.py      # 停止后台服务
├── 使用方法.md               # 完整功能使用指南（必读）
├── scripts/
│   ├── avdanyu-server.py    # 本地服务：静态页面/数据库/译文同步/翻译中继/磁力与预告片解析
│   ├── avdanyu-exporter.user.js  # 油猴脚本：从来源网站导出月度数据
│   ├── avdanyu-merge.py     # 月度数据整合入库（自动去重、保留封面）
│   ├── dedupe_works.py / backfill-covers.py / retranslate-en.py  # 维护工具
│   └── README.md            # 脚本与维护命令详解
└── avdanyu-data/            # 数据目录（不入库，见下）
    ├── avdanyu.db           # SQLite 全量数据库
    ├── months/              # 月度源文件
    └── translations.json    # 译文缓存
```

## 🔧 翻译引擎配置（可选）

在 `avdanyu-data/zhipu-config.json` 填入智谱 API Key 即可启用 GLM 大模型翻译（`model` 留空默认 `glm-4.6`），保存后无需重启服务；也可用环境变量 `ZHIPU_API_KEY`。未配置时自动使用免费谷歌引擎，功能不受影响。详见[使用方法 · 标题自动翻译](使用方法.md)。

## 📦 数据备份

`avdanyu-data/`（数据库、译文等）通过 `.gitignore` 排除在 git 仓库之外，作者的数据快照备份存放在 [Releases](https://github.com/yuanfang9527/avdanyu-viewer/releases) 附件中（**出于安全考虑，备份不含 `zhipu-config.json`，恢复后请自行配置**）。下载解压到项目根目录即可使用。
